                JumpLogger

                  Show full text

                  This perl-module allows to check whether a jump in an BPE has been performed.

                  "JumpLogger.pm"

                  It is located in ck18y530/GPSUSER/SCRIPT.

                  If you want to use it

                  Copy the JumpLogger.pm to your SCRIPT-directory.

                  Change the path in the "JumpLogger.pm" (line 11) to a location where you want to have to LOG-file. This LOG-file consists of the Jumps performed.

                  To use it in any SCRIPT

                  import the module (in the very beginning after Header and after @ISA...)

                  use lib "$ENV{HOME}/GPSUSER/SCRIPT";

                  use JumpLogger qw(logJump);

                  And then before the prtGoto use the "logJump-command". For example:

                  logJump($bpe, $param2);

                  prtGoto(\$bpe,$param2) ;

                  You can also use the jumpAndLog-function, but this one has not been tested recently, so no guarantee that it's working.

                      RetryHelper

                        Show full text

                        A perl-Module which allows to rerun a specific Bernese Program. Use it for example like this:

                        First import the module

                        use lib "$ENV{HOME}/ZDGNSS_RUN/perl;

                        use RetryHelper qw(run_with_retry);

                        Example

                        my $PGMNAM = "SATMRK";

                        run_with_retry($bpe, $PGMNAM,10);

                        The module can be found in ~/ZDGNSS_RUN/perl

                        Multiple functions are available in this module

                        • run_with_retry
                        • run_with_retry_noerror
                        • Used in CODSPP_E
                        • run_retry_goto

                        You may adapt the path for the log-file in the perl-module (line 25).

                                                        Python_Controller

                                                          Show full text

                                                          Start Perl Controllers in defined sequence

                                                          The tool can be found in /storage/homefs/ck18y530/perl/ZDGNSS

                                                          • start_bpe_gui.py

                                                          This tools allows to start perl-scripts in a dedicated sequence. The order can be changed by moving the jobs up or down. The available Perl Controller start parts of the full processing chain.

                                                          Following the Bernese-style, one can choose the campaign (and partition), the first session and the number of sessions. To generate a LOG for the BPE run, it is possible to specify name for the output file. The wait-condition may be used to enforce a waiting between the starting of the scripts. The function "Dry-Run" simply shows the commands which would be executed. When using this tool for the first time, it is recommended to try the "Dry-Run" first (before "START BPE").

                                                                      pcf_viewer

                                                                        Show full text

                                                                        This Tool allows to inspect a PCF-file including the PCF itself, the input-files, and the scripts.

                                                                        First select a PCF, and then by clicking on the lines in the PCF, the corresponding input-file and script appears.

                                                                        The Script can be edited (first press the "Locked" button). Clicking on a PCF variable leads to a scanning of the input-file and script whether this variable is used somewhere. Whenever a match is found, it is marked (maybe scroll down).

                                                                        Additionally, notes can be made for every PID, which are saved in a file named "PCFFILENAME_help.json" in the PCF-directory.
