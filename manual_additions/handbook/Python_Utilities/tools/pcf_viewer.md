This Tool allows to inspect a PCF-file including the PCF itself, the input-files, and the scripts.
First select a PCF, and then by clicking on the lines in the PCF, the corresponding input-file and script appears.
The Script can be edited (first press the "Locked" button). Clicking on a PCF variable leads to a scanning of the input-file and script whether this variable is used somewhere. Whenever a match is found, it is marked (maybe scroll down).
Additionally, notes can be made for every PID, which are saved in a file named "PCFFILENAME_help.json" in the PCF-directory.
