## Overview

This documentation describes the architecture, operation and maintenance of the ZDGNSS processing using the Bernese GNSS software.

The documentation covers:

- Python controller
- Perl controller
- BPE PCF's
- Scripts

## Processing chain

The general processing structure is:

Python Controller  
↓  
Perl Controller  
↓  
BPE Workflow  
↓  
PIDs
↓  
Bernese Programs/ Scritps
